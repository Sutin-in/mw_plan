# Checklist ก่อนเปิดใช้ระบบจริง (Go-live checklist)

ระบบควบคุมแผนและ PPR · Phase 1 · ตามข้อตัดสินใจ D-40 (spec §0) และ §40.14

**วิธีใช้**

- ทำตามลำดับใน `docs/IT_HANDOFF.md` แล้วกรอกผลที่นี่ทีละข้อ
- ทุกข้อต้องมี **หลักฐาน** ที่ตรวจย้อนหลังได้ เช่น ไฟล์ผลคำสั่ง (`--out`) หรือชื่อเอกสาร ให้เก็บหลักฐานไว้ในโฟลเดอร์เดียวกัน (เช่น `D:\ppr\golive\`) แล้วเขียนชื่อไฟล์ลงช่อง "หลักฐาน"
- ผลมีได้เพียง: **PASS** (ผ่าน ตรวจแล้ว), **FAIL** (ไม่ผ่าน ต้องแก้ก่อนเปิด), **WARN** (เปิดได้ แต่ต้องรับทราบและจัดการ), **OPEN** (ยังไม่มีหลักฐาน/ยังไม่ได้ตัดสินใจ)
- **OPEN ไม่ใช่ PASS** ข้อที่ยัง OPEN อยู่ในส่วน C แยกต่างหาก และห้ามทำเครื่องหมายว่าผ่าน
- ผู้อนุมัติขั้นสุดท้ายคือ **เจ้าของระบบ** (ส่วน D)

## C. รายการที่ยังเปิดอยู่ (OPEN) - ไม่ใช่ PASS

ข้อเหล่านี้ยังไม่มีหลักฐานจาก HOSxP หรือยังไม่ได้ตัดสินใจ ระบบทำงานได้โดยไม่เดาค่าแทน (ผลตามคอลัมน์ "ระหว่างที่ยัง OPEN") **ห้ามทำเครื่องหมายว่า PASS** จนกว่าจะมีหลักฐานและบันทึกการตัดสินใจ (ADR) แล้ว

| # | รายการ | สถานะ | ระหว่างที่ยัง OPEN | สิ่งที่ต้องได้เพื่อปิดข้อนี้ |
|---|---|---|---|---|
| C1 | **G-4** สถานะ HOSxP ที่ถือว่า PR ปิดแล้ว (ปิด PPR อัตโนมัติ) | **OPEN** | ไม่มี PPR ใดถูกปิดอัตโนมัติ | หลักฐานสถานะจริงจาก HOSxP + ข้อตัดสินใจของเจ้าของระบบ |
| C2 | **การยกเลิก PR (D-30)** ค่าสถานะใน HOSxP ที่หมายถึง "ยกเลิก" | **OPEN** (แม้ตั้งค่า `[status_map]` แล้ว ก็ยัง OPEN จนกว่าจะแนบหลักฐาน) | ถ้าไม่ได้ตั้งค่า ระบบไม่รู้ว่า PR ถูกยกเลิก จะไม่คืนยอดแผนให้อัตโนมัติ | PR ที่ถูกยกเลิกจริง 1 ใบ + ค่าสถานะที่อ่านได้ (`hosxp-verify --pr`) + การยืนยันของ IT |
| C3 | **ยอดเบิก/คืนจากคลัง (D-39)** query `[stock_movement]` ที่ยืนยันแล้ว | **OPEN** ถ้า `hosxp-verify` รายงานว่า OPEN | รายงานการใช้แผนกลางแสดง "ยังไม่มีข้อมูล" ไม่ลงบัญชีแผนไม่ว่ากรณีใด | query + ผู้ยืนยัน/วันที่/เลขอ้างอิง + การจับคู่ประเภทเบิก/คืน (รวมวิธีบันทึกการรับคืน) |
| C4 | อื่น ๆ ที่ `hosxp-verify` / `first-start --check` รายงานเป็น OPEN | **OPEN** | ตามที่รายงานระบุ | ตามที่รายงานระบุ |
